# Menu navigation samples

Embedded WAV one-shots from [pepperonas/sound-effects](https://github.com/pepperonas/sound-effects), MIT licensed, copyright 2026 Martin Pfeffer. The project's MIT license retains this attribution. These files are byte-identical copies of the corresponding generated files:

| BeatByte file | Source under `sound-effects/output/` |
| --- | --- |
| `tap_minimal.wav` | `interface/clicks/tap_minimal.wav` |
| `click_soft.wav` | `interface/clicks/click_soft.wav` |
| `click_crisp.wav` | `interface/clicks/click_crisp.wav` |
| `hover.wav` | `interface/ui/hover.wav` |
| `key.wav` | `interface/typing/key_1.wav` |

All are short (18–120 ms) and normalized to −0.9 dBFS at the source; BeatByte plays each with its own gain (`sfx::MenuVoice`) so that they sit at an even, quiet level next to the classic synthesized beep, which is still offered.
